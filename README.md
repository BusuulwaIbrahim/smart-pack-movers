# SmartPack Movers Uganda - SMC Limited
Corporate website (pure HTML, CSS, vanilla JS). The complete single-page site is in `index.html`; About, Services, and Contact are sections linked from the navigation.

## Deploy on GitHub Pages
1. Create a repository and upload all files from this folder to the root (`.nojekyll` included).
2. Settings > Pages > Deploy from a branch > `main` / `(root)`.
3. Open the URL GitHub gives you. Set each page's `og:image` to the absolute public URL of a hosted truck photo, add its `og:url`, and replace the social links in the footer with your real accounts.
